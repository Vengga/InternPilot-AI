# 3-minute demo script

**0:00 – 0:25 — Hook.** Land on the home page. "Applying for internships means decoding a job
description, matching it to your resume, and rewriting everything for every role. InternPilot is an
autopilot that does the flying — you stay the pilot." Toggle light/dark on camera; show the 3D nav core.

**0:25 – 0:45 — The pipeline.** Scroll to the 7-stage section. "Seven focused agents, not one prompt.
Each hands structured output to the next, so it's modular and production-shaped."

**0:45 – 2:10 — Live run (the core).** Open **/studio**, click **Load sample** (or paste real data),
hit **Run autopilot**. Narrate the stage rail lighting up: parse → analyze → match → recommend →
generate. Show the **fit gauge**, the matched/partial/**missing** chips, and the recommended projects.

**2:10 – 2:40 — Human-in-the-loop.** Edit a line of the cover letter. "Nothing is sent automatically —
I review and approve." Click **Approve & export**; the Markdown pack downloads.

**2:40 – 3:00 — Memory + cloud.** Point to the **Agent memory** panel — recurring skill gaps from past
runs. Close on the Stack section: "Every reasoning step runs on Qwen on Alibaba Cloud Model Studio."

> If using demo data (no key), say so once: "running on built-in demo data here; with a Model Studio
> key the same code calls live Qwen." Keep total length under 3:00 — judges may stop at 3 minutes.
